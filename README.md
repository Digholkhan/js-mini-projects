# Beginner JavaScript Projects

Nine small vanilla JavaScript projects. Open any project's `index.html` in a browser.

- `type-js` - typing speed practice
- `counter-up` - increase, decrease, and reset a number
- `interactive-calculator` - basic calculator
- `theme-switcher` - switch between light and dark themes
- `rock-paper-scissors` - play against the computer
- `tic-tac-toe` - two-player 3x3 game
- `multiplication` - multiplication table generator
- `weather-app` - look up weather with the Open-Meteo API
- `digital-clock` - live clock with date

No installation is required. Each folder is independent and contains its own `index.html`, `style.css`, and `script.js`.
